## 📘 Overview  
This repository contains **10 JavaScript operator & logic-based problems** from **Assignment 2**.  
Each question is implemented in a **separate `.js` file**, tested using **browser console or Node.js**.  
Focus is on **scope, strings, Math, arrays, Booleans, loops, and conditional logic**.

---

## 🧩 Topics Covered  
- Scope Conflict Resolver (global vs local variables)  
- String Manipulation Report (trim, case, replace, length)  
- Math Utility Dashboard (round, sqrt, power, random)  
- Array Performance Analyzer (max/min, average, pass count)  
- Boolean Logic Access System (secure/unsafe home check)  
- Event-Based Counter Simulation (increment/decrement with scope)  
- Customer Feedback Processor (word count & sentiment check)  
- Dynamic Discount Evaluator (category-wise + overall discount)  
- Odd–Even Number Analyzer (FizzBuzz-style classification)  
- Departmental Employee Evaluator (rating via nested arrays)

## 🛠️ Technologies Used  
- **JavaScript (ES6)**  
- **Console / Node.js** for running scripts  
- **No external libraries** – pure JS logic with clear comments and indentation
